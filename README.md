# FileWheel

Packaged FileWheel application for Windows x64.

## Download and run

1. Download [FileWheel-Windows-x64.zip](https://github.com/xrobinx/FileWheel/releases/latest/download/FileWheel-Windows-x64.zip).
2. Extract the ZIP completely.
3. Open the extracted `FileWheel` folder and run `FileWheel.exe`.

Keep the `engines` folder beside `FileWheel.exe`; it contains the bundled `ffmpeg.exe` engine.

## Repository contents

The ready-to-run app is attached to [GitHub Releases](https://github.com/xrobinx/FileWheel/releases). This repository hosts the packaged application supplied for upload; source code is not included.

A SHA-256 checksum file is included with the release to verify the download.
