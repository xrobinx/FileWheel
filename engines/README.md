# Optional FFmpeg engine

Download FFmpeg separately using the instructions in the main README. Place `ffmpeg.exe` here before building, or in an `engines` directory beside your published `FileWheel.exe`. The project copies files in this directory to its build and publish output.

The original local installation used Gyan's FFmpeg 7.1 essentials build under GPLv3-or-later. No FFmpeg executable or FFmpeg source is included in this MIT-licensed repository. Retain the upstream notices and comply with FFmpeg's own license if you redistribute it.
